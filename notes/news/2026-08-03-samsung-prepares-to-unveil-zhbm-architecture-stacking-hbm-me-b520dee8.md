## Samsung Prepares to Unveil 'zHBM' Architecture Stacking HBM Memory Directly on GPU

zHBM represents a potential architectural disruption in AI memory supply; if it gains GPU OEM traction, SK Hynix's HBM premium position could erode, and for portfolio names with HBM supply chain exposure the competitive moat durability question becomes more urgent.

- Samsung is set to reveal 'zHBM,' a design that stacks HBM memory directly on a GPU, targeting the AI memory bandwidth bottleneck.
- This is a direct architectural challenge to the conventional separate-package HBM model in which SK Hynix (000660.KS) currently leads.
- If adopted by GPU OEMs, zHBM could meaningfully shift the competitive balance between Samsung (005930.KS) and SK Hynix in AI memory.
- High classifier confidence; this is a structural competitive development, not incremental product iteration.

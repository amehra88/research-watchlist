## Apple Reportedly Testing CXMT Chinese Memory Chips for iPhones and MacBooks Amid AI-Driven Supply Crunch

Apple qualifying Chinese memory would mark a supply-chain realignment of the first order for Korean memory incumbents; even partial iPhone memory displacement from SK Hynix or Samsung carries significant volume implications given Apple's scale, and validates CXMT's competitive progression.

- Apple is testing memory chips from China's CXMT for potential use in iPhones and MacBooks, per reports attributed to Reuters and WSJ.
- The testing is framed against a backdrop of AI-driven tightness in global memory supply.
- If qualified, CXMT chips could displace current supply from SK Hynix and/or Samsung across Apple's device lineup.

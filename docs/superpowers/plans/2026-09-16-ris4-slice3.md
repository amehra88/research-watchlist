# RIS4 slice 3 — Ask Claude + alert enrichment — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** (a) the thesis and stage alert cards, and the per-ticker Thesis tab, carry the evidence behind each event instead of one-line ids; (b) the portal can ask Claude about a note, a ticker, or the whole vault through the artifact `sample` capability, with page-side retrieval over the bundle.

**Spec:** `docs/superpowers/specs/2026-09-15-RIS4-plan.md` (RIS4) §Phase 2 "Ask". Slice 2 delivered the builder + read-only app (`docs/portal/README.md`, `scripts/portal/`). Operator feedback 2026-09-16: "thesis alerts and stage alerts don't seem to provide much information".

**Architecture:** builder-side enrichment only for (a): new `scripts/portal/evidence.py` indexes `state/thesis/evidence_log.jsonl` (2,685 rows: `source, source_id, ref, date, title, assumption_id, direction ∈ confirm|challenge|neutral, strength 0-3, why, quote, cross_ticker, ts, ticker`) and `state/transcripts/exchanges.jsonl` (30 MB, gitignored, droplet-only: `document_id, ticker, event_type, event_date, period_key, section, speaker_type, speaker_name, speaker_title, speaker_firm, text, view_url, ...`). Cards gain a structured `items` array; `text` stays as the fallback. For (b): app-side only, `claude.use("sample")`, no builder change except documenting the capability declaration in the publish runbook.

**Tech stack:** as slice 2 (Python 3 stdlib + PyYAML; plain-assert tests with the verbatim `__main__` runner from `scripts/portal/test_reports.py`; vanilla JS app in `scripts/portal/app/`; esprima parse check via a throwaway venv).

## Global Constraints

- All slice-2 Global Constraints still apply (absolute `REPO`; never write into `notes/`, `config/`, `state/`; gaps tolerated with one log line; fixtures only in tests; budgets; page contract; `esc()` everywhere; `python3 scripts/check.py` 0 issues).
- Bundle growth: the whole bundle must stay under the slice-2 budgets (files ≤ 240, total ≤ 48 MB); evidence attached to ticker bundles is capped (≤ 6 rows per assumption, quotes ≤ 300 chars, `why` ≤ 200 chars).
- `sample` contract (artifact runtime 0.2.50, read `/tmp/claude-0/bundled-skills/2.1.273/6a07e88d48cc89f50ec56a1d166c31f3/artifact-capabilities/0.2.50/sample.d.ts` — it is authoritative): `const sample = await claude.use("sample")` (null → hide every Ask affordance; never read `window.claude.sample`); `await sample(input, {onText, signal, tools, modelTier, cache})` → `{text, truncated, modelTierApplied}`; input ≤ 64 KiB total; `onText({text, delta})` gives the WHOLE text so far — assign, never `+=`; a NEW `AbortController` per call; errors are `{code, message, text?}` — branch on `code`: `not_granted`/`sampling_disabled`/`not_declared`/`capability_disabled`/`capability_removed`/`tools_unavailable` → hide the feature; `rate_limited`/`session_expired`/`refused`/`empty_completion`/`upstream_error`/`prompt_too_large` → tell the viewer, keep the control, never auto-retry; `cancelled` → restore idle UI; `tools:[{name, description, inputSchema, execute}]` → several paid rounds, `cache` must be omitted/false with tools; `sample.limits()` reports `maxPromptBytes`, `tools.maxCount` (16 on this account), `images` (absent here). Call only on an explicit tap, never on load or in a loop. Consent is per view on first call: show "Thinking…" from the call until the first `onText`.
- Phase 0 facts: `claude.use("sample")` resolves in the iPhone Claude app; a quick-tier call answered in ~4 s; page tools are available (16).
- No other capability in this slice (no `mcp`, `db`, `assets`).

## Task 1: Evidence index + thesis alert enrichment — `scripts/portal/evidence.py`, `reports.py`, `build_portal.py`

**Interfaces (produce):**
- `evidence.load_index(paths=None) -> dict[(ticker, assumption_id), list[row]]` from `state/thesis/evidence_log.jsonl`; each row trimmed to `{date, source, source_id, ref, title, direction, strength, why[:200], quote[:300], cross_ticker}`; missing file → `{}` + one log line.
- `evidence.top(rows, n=6) -> list`: sort by `strength` desc, then `date` desc; drop `strength == 0` when at least one row with strength ≥ 1 exists; cap `n`.
- `evidence.attach_thesis(bundle: dict, index) -> None`: sets `bundle["thesis"]["evidence"] = {assumption_id: top(rows)}` for every assumption in `bundle["thesis"]["fm"]["assumptions"]` (empty list when none) — called from `build_portal`'s ticker stage before the file is written (find the exact place; keep the manifest hashing intact). Tickers with no thesis → no key.
- `reports._thesis_alert_card` (modify): keep `text` (backward compatible) but build it from `items` = grouped by ticker then assumption: `{ticker, assumption_id, statement (from the ticker's `_thesis.md` frontmatter — load via `thesis_io.load` or `vault.load_note` on the discovered ref; fallback to the id), from, to, strength3_challenges: n, evidence: top(rows, 3) filtered to rows dated within 7 days of the card date, note_links: [...]}`; DROP "earnings note landed" lines from the card (they remain in the Notes tab); the `text` becomes one paragraph per item: `TICKER — <statement> — open→challenged (3 evidence) · <date> <source>: "<quote[:160]>"`.
- Card JSON: `{id, kind, date, title, text, bytes, items:[...]}`.

**Tests (`test_evidence.py`, `test_reports.py`):** index shape on a fixture evidence log; `top()` ordering, strength-0 drop rule, cap; `attach_thesis` on a fixture bundle with 2 assumptions (one without evidence → `[]`); thesis card groups 3 lines for one assumption into one item, drops earnings-note-landed lines, keeps `text` non-empty; card without evidence still renders. Live check: rebuild ticker bundles for FPS and NVDA and paste `len(evidence)` per assumption + the enriched FPS card text.

## Task 4: App — Ask Claude (`scripts/portal/app/ask.js`)

**Files:** create `scripts/portal/app/ask.js` (loaded after `app2.js` in `index.html`; add to `build_portal.OWNED_PATHS` + copy list + `publish_files` is automatic); modify `app.js`/`app2.js`/`styles.css` for entry points.

**Behaviour:**
- Boot: `const sample = await claude.use("sample")`; null → no Ask UI anywhere (no placeholder buttons). `sample.limits()` once; tools mode only when `limits.tools` exists.
- Entry points: note view ("Ask about this note"), ticker header ("Ask about NVDA"), Today header and `#/more/ask` ("Ask the desk"). A single bottom-sheet panel: question input (`id="ask-q"`), Ask button, Stop button (visible while running), streaming answer area (markdown-rendered via `md()` on completion, plain text while streaming), status line ("Thinking…" until first `onText`; tier applied; truncated notice), error copy by code (map above), "Copy answer" button (clipboard API in try/catch; downloads are blocked so no file save), and a muted note "Save to vault arrives in slice 5".
- Prompt budgets: **note mode** = instructions (≤ 2 KB) + note body sliced to 40 KB + question, `cache` default, `modelTier: "default"`. **ticker mode** = instructions + `ticker_brief(T)` (name/tier/themes/scores/assumptions with status + last 5 note titles+dates, ≤ 4 KB) + the latest note's first 12 KB + question; no tools, cache default. **desk mode** (global) = tools: `search_vault({query, ticker?, theme?, kinds?, limit?})` over the loaded `data/search.json` using the mirrored tokenizer from app2.js (returns ≤ 8 hits `{id, title, date, ticker, kind, snippet, f, s}`), `get_note({id, section?})` (loads the ticker bundle and returns the note or section text ≤ 10 KB with a `[truncated]` marker), `ticker_brief({ticker})`; a running byte budget of 32 KB across tool results — past it, `execute` throws "budget exhausted, answer now"; `cache` omitted; `modelTier: "default"`; instructions (leading user turn) state today's date, the scope, "cite note ids in [brackets]", "say when the vault has nothing", "never invent numbers". `AbortController` per call; abort on route change.
- Never call `sample` on load; every call is a tap. Log nothing sensitive.

**Verification:** esprima parse; headless: with a fake `window.claude.use` returning a stub `sample` that streams three `onText` calls then resolves, assert the panel renders "Thinking…" → streamed text → final markdown, Stop aborts (stub rejects `{code:"cancelled"}`), each error code maps to copy, and that with `use()` → null no Ask buttons exist in any screen's HTML.

# RIS4 slice 2 — read-only portal bundle + app — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A droplet-built data bundle (`portal_build/`) and a vanilla-JS mobile app that together give the operator read-only access to the research vault from the iPhone Claude app: Today, Tickers (Notes/Thesis/Signals/News/Insiders/ETF trades), Themes, Ideas, Scores, ETF trades, Reports archive, Search, Status. No capabilities yet (Ask, live panels, capture come in slices 3–5) except `localStorage` read markers.

**Spec:** `docs/superpowers/specs/2026-09-15-RIS4-plan.md` (RIS4). Phase 0 results: `docs/portal/phase0.md`.

**Architecture:** `scripts/portal/build_portal.py` walks `notes/`, `config/`, `state/` and the daily report streams on the droplet (absolute `REPO = Path("/root/research-watchlist")`, never the worktree) and writes JSON bundles + copies `scripts/portal/app/*` into `portal_build/`. The app fetches `manifest.json` first and every other file lazily. Markdown renders client-side with vendored markdown-it; wikilinks are resolved server-side into hash routes.

**Tech stack:** Python 3 stdlib + PyYAML (installed); no pytest on the droplet — tests are `test_*.py` modules with a `__main__` runner (copy the runner block from `scripts/v3_ingest/test_transcript_ingest.py` verbatim) run as `python3 scripts/portal/test_x.py`. App: vanilla ES2020, no build step, `vendor/markdown-it.min.js` (14.1.0, from cdnjs, sha256 recorded in manifest).

## Global Constraints

- **Absolute repo root.** Every module defines `REPO = Path("/root/research-watchlist")` and reads data from there, so the code behaves identically from a worktree. Output dir default `REPO / "portal_build"` (gitignored — verify with `git check-ignore portal_build`).
- **Never write into `notes/`, `config/`, or `state/`** from any slice-2 code, except `identity.py --merge-names` (Task 2), which appends one marked block to `config/ticker_identity.yaml` and nothing else.
- **Reuse before writing:** frontmatter via `scripts/thesis/sources.py:_fm_and_body(path)`; `sources._iso_from_name`; `scripts/thesis/thesis_io.py` `load(ticker)`, `tier_of`, `watchlist_scores`; `scripts/thesis/thesis_report.py` `rank_movers`, `ranking_rows`, `pending_proposals`, `stale_assumptions`, `alert_events`; `scripts/topics/theme_notes.py` `theme_state`, `affects_map`; `scripts/topics/stage_alert.py` `snapshot_stages`, `gated_themes`, `render`; `scripts/chunking/ingest_metrics.py` `id_maps`, `universe`; `/root/daily/combine_and_send.py` `REPORTS` (import via `importlib` with a literal fallback). Import with `sys.path.insert(0, str(REPO / "scripts"))`.
- **Frontmatter-less dated ticker notes (77 of 109)** get `{ticker: <dir>, date, period}` synthesized from the path — never skipped.
- **Provenance on every note record:** `provenance` ∈ `machine | headline_only | operator_reviewed`, derived from `extraction_source` / `summarized: false` / `reviewed_by_operator` / `status_source == "operator"`.
- **Wikilinks** (`[[T]]`, `[[T/_thesis|T]]`, `[[T/_thesis]]`, `[[themes/slug|slug]]`) are rewritten server-side to markdown links `[label](#/ticker/T)`, `[label](#/ticker/T/thesis)`, `[label](#/theme/slug)`; unknown targets become plain `label`.
- **Budgets (build fails non-zero on breach):** ≤ 240 files, any single text file ≤ 14 MB, total ≤ 48 MB, `index.html` ≤ 1 MB.
- **Gaps are tolerated, never errors:** a missing report file, an absent state file, an empty day → omit and log one line.
- **Sizes:** news window 30 days trimmed (no `cluster_headlines`, first `source_urls` only), SEC window 30 days frontmatter-only, reports 14 days, substacks/podcasts 30 days.
- **App runs at ~400 px**, theme-aware tokens (light on bare `:root`, dark under `@media (prefers-color-scheme: dark)` guarded `:root:not([data-theme="light"])` and again under `:root[data-theme="dark"]`), explicit `body` background, safe-area insets on the fixed bottom bar, 44 px targets, `font-variant-numeric: tabular-nums` on numbers. Every screen shows "as of {built_at}".
- **No capability code in slice 2** (no `claude.use` calls) except a guarded `localStorage` read-marker store wrapped in try/catch.
- Run `python3 scripts/check.py` before every commit; it must report 0 issues.

## Task 1: Vault walker — `scripts/portal/vault.py`

**Files:** create `scripts/portal/__init__.py`, `scripts/portal/vault.py`, `scripts/portal/test_vault.py`, fixtures under `scripts/portal/fixtures/vault/` (a tiny fake `notes/` tree with: `NVDA/20260512-4Q26.md` without frontmatter, `NVDA/_thesis.md` with the real 11-key frontmatter shape, `NVDA/_themes.md`, `GOOGL/20260303-conf-morgan-stanley-tmt.md`, `NVDA/synthesis-20260602-run8.md`, `themes/ai_inference_margin_compression.md`, `reports/thesis-delta-20260914.md`, `substacks/2026-06-24-x.md`, `podcasts/2026-06-08-hObRMv6q.md`, `flows/20260915-flows.md`, `openai.pvt/_profile.md`, `inbox/test.md`). Copy real frontmatter shapes from the live vault when building fixtures (read-only).

**Interfaces (produce):**
- `NoteRef` dataclass: `path: Path, rel: str, ticker: str|None, kind: str, date: str|None (ISO), period: str|None, title: str, size: int`
- `classify(rel: str) -> tuple[kind, ticker|None, date|None, period|None]` with kinds: `earnings` (`^([A-Z0-9.\-]+|[a-z]+\.pvt)/(\d{8})-([1-4]Q\d{2})\.md$`), `conference` (`/(\d{8})-conf-`), `synthesis` (`/synthesis-(\d{8})`), `news_note` (`/(\d{8})-news-`), `thesis` (`/_thesis\.md`), `theme_index` (`/_themes\.md`), `profile` (`/_profile\.md`), `theme` (`themes/`), `report` (`reports/`), `substack`, `podcast`, `foreign`, `flow`, `sector`, `pvt_profile` (`*.pvt/_profile.md`), `other`. `inbox/`, `news/`, `sec/` are excluded from `discover()`.
- `discover(notes_dir: Path = REPO/"notes") -> list[NoteRef]`
- `load_note(ref) -> dict` = `{id, rel, ticker, kind, date, period, title, fm, body, sections: [{h, text}], provenance}`; `fm` from `_fm_and_body`, falling back to the synthesized dict; `title` = first `# ` line else stem; `sections` split on `^## ` keeping the numbered heading text (`"5. AI positioning signal"`).
- `resolve_wikilinks(text, known_tickers: set, known_themes: set) -> str`
- `ticker_bundle(ticker, refs, names, known_tickers, known_themes) -> dict` = `{ticker, name, tier, themes, scores, thesis: {fm_without_body, body}, theme_index_body, notes: [load_note(...) sorted date desc, excluding thesis/theme_index], profile}` — tier/themes/scores via `thesis_io.tier_of` / `watchlist_scores` (fall back gracefully when a ticker has no watchlist entry: tier `"none"`).
- `ingest_bundles(refs, days=30) -> dict[name, {items:[...]}]` for `substacks`, `podcasts`, `foreign`, `flows` (14 d), `sector`, `pvt` — each item `{id, date, title, tickers, themes, source, body(wikilinks resolved)}`.
- `signal_reads(note) -> dict|None`: for `earnings`/`conference` notes, the text of sections whose heading starts with `5.` / `6.` / `7.` → `{ai_positioning, competitive_advantage, investor_interest}` (first 600 chars each, stripped); `None` when absent.

**Tests (`test_vault.py`):** classification table (every kind, plus `inbox/` excluded); frontmatter-less note synthesizes ticker/date/period; `sections` splits the 10-step skeleton and `signal_reads` picks §5/§6/§7; all four wikilink forms resolve and an unknown target degrades to plain text; `ingest_bundles` window filter; `provenance` mapping for the three cases.

## Task 2: Identity — `scripts/portal/identity.py`

**Files:** create `scripts/portal/identity.py`, `scripts/portal/test_identity.py`. Fixture already present: `scripts/portal/fixtures/names_backfill_20260915.json` (`{"as_of","source","names":{ticker:name}}`, 96 entries).

**Interfaces:**
- `load_universe() -> list[dict]`: every entry of `tier_1_bctk`, `tier_2_active_candidates`, `tier_3_watchlist` from `config/watchlist.yaml` → `{ticker, tier, themes, scores?}` (first tier wins for the 19 dual-listed; record `also_in`), plus tickers that have a `notes/<T>/` dir but no watchlist entry (`tier: "none"`, `orphan_notes: True`) — e.g. ROKU.
- `display_names() -> dict[ticker, name]`: union in this precedence: `config/ticker_identity.yaml[T].name` → `private_drivers[].name` keyed by `pvt_id` → `tier_4_ecosystem[].name` keyed by `id` → the merged backfill block → the bare ticker.
- `factset_ids() -> dict[ticker, id]` via `ingest_metrics.id_maps`.
- CLI `python3 scripts/portal/identity.py --merge-names FILE [--write]`: appends to `config/ticker_identity.yaml` a block
  ```
  # ---- portal name backfill 2026-09-15 (source: <json.source>) ----
  <TICKER>:
    name: "<name>"
    factset_id: "<T>-US"          # per id_maps default; foreign tickers keep their existing mapping if any
    google: '"<name>" OR <T> stock'
  ```
  ONLY for tickers not already present; re-parses the whole file with `yaml.safe_load` before and after and aborts (non-zero, file untouched) if the after-parse fails or loses any pre-existing key. - `--missing` prints tickers still without a name after the union (expect 0 after merge).

**Tests:** precedence order; dual-tier `also_in`; orphan-notes ticker; merge is idempotent (second run appends nothing); merge refuses when the after-parse would drop a key (simulate with a fixture copy in a tmp dir — never the real config).
